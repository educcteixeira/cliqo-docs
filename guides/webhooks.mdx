# Webhooks

Webhooks permitem que sua aplicação receba notificações em tempo real quando eventos ocorrem na Cliqo — emails abertos, links clicados, formulários AMP submetidos, compras convertidas.

## Configurar um Webhook

No painel: **Configurações → Webhooks → Adicionar endpoint**

Ou via API:

```bash
curl -X POST https://api.cliqo.io/v1/webhooks \
  -H "Authorization: Bearer cliqo_sk_live_xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://sualoja.com.br/api/cliqo-webhook",
    "events": ["email.opened", "email.clicked", "amp.form_submitted", "campaign.converted"]
  }'
```

## Eventos disponíveis

### Email
| Evento | Quando dispara |
|--------|----------------|
| `email.sent` | Email entregue ao servidor de destino |
| `email.opened` | Email aberto pelo destinatário |
| `email.clicked` | Link clicado no email |
| `email.bounced` | Email retornou (hard ou soft bounce) |
| `email.complained` | Marcado como spam |
| `email.unsubscribed` | Descadastro via link |

### AMP (exclusivo Cliqo)
| Evento | Quando dispara |
|--------|----------------|
| `amp.form_submitted` | Formulário AMP submetido dentro do email |
| `amp.spin_wheel` | Roleta girada — inclui o prêmio ganho |
| `amp.quiz_answered` | Quiz respondido — inclui as respostas |
| `amp.cashback_redeemed` | Cashback resgatado dentro do email |
| `amp.nps_submitted` | NPS submetido dentro do email |

### Conversão
| Evento | Quando dispara |
|--------|----------------|
| `campaign.converted` | Compra atribuída a uma campanha |
| `campaign.revenue` | Receita atribuída (requer Pixel instalado) |

## Verificar assinatura

Cada requisição inclui o header `Cliqo-Signature` para validar autenticidade:

```javascript
import crypto from "crypto";

function verifyWebhook(payload, signature, secret) {
  const expected = crypto
    .createHmac("sha256", secret)
    .update(payload)
    .digest("hex");
  
  return `sha256=${expected}` === signature;
}

// Em sua rota de webhook:
app.post("/api/cliqo-webhook", (req, res) => {
  const signature = req.headers["cliqo-signature"];
  const isValid = verifyWebhook(
    JSON.stringify(req.body),
    signature,
    process.env.CLIQO_WEBHOOK_SECRET
  );
  
  if (!isValid) {
    return res.status(401).send("Unauthorized");
  }
  
  const event = req.body;
  
  if (event.type === "amp.cashback_redeemed") {
    // Creditar cashback no sistema da loja
    await creditCashback(event.data.contact_email, event.data.amount);
  }
  
  res.status(200).send("OK");
});
```

## Retentativas

Se seu endpoint retornar um status diferente de `2xx`, a Cliqo tentará reenviar o webhook automaticamente:

| Tentativa | Delay |
|-----------|-------|
| 1ª | Imediato |
| 2ª | 5 minutos |
| 3ª | 30 minutos |
| 4ª | 2 horas |
| 5ª | 8 horas |

Após 5 falhas, o webhook é marcado como `failed` e você recebe uma notificação por email.
