# Cliqo API

Cliqo é a única plataforma brasileira com suporte a **AMP for Email** — emails interativos que funcionam dentro do Gmail, sem redirect, sem nova aba.

A API REST da Cliqo permite que você envie campanhas, gerencie contatos, rastreie comportamento de navegação e dispare automações de WhatsApp — tudo em uma única integração.

## Base URL

```
https://api.cliqo.io/v1
```

Todas as requisições devem usar HTTPS. Requisições HTTP são rejeitadas.

## Formato de resposta

A API retorna JSON em todas as respostas, incluindo erros.

```json
{
  "id": "cmp_01H9Z3X2Y1K8M4N5P6Q7R8S9T0",
  "object": "campaign",
  "status": "sent",
  "created_at": "2026-05-20T10:00:00Z"
}
```

## Códigos HTTP

| Código | Significado |
|--------|-------------|
| `200` | Sucesso |
| `201` | Criado com sucesso |
| `400` | Requisição inválida — verifique os parâmetros |
| `401` | Não autenticado — API key inválida ou ausente |
| `403` | Sem permissão para este recurso |
| `404` | Recurso não encontrado |
| `422` | Entidade não processável — dados inválidos |
| `429` | Rate limit atingido |
| `500` | Erro interno do servidor |

## Rate Limits

| Plano | Requisições / minuto |
|-------|---------------------|
| Free | 60 |
| Starter | 300 |
| Growth | 1.000 |
| Enterprise | Sob consulta |

## Ambientes

Use a mesma API key para todos os ambientes. O campo `mode` na API key indica se é `live` ou `test`.

```bash
# Live (produção)
cliqo_sk_live_...

# Test (sandbox)
cliqo_sk_test_...
```
