# SDK Node.js

```bash
npm install cliqo
# ou
yarn add cliqo
```

## Requisitos

- Node.js 18+
- TypeScript 5+ (opcional, mas recomendado)

## Inicialização

```typescript
import { Cliqo } from "cliqo";

const cliqo = new Cliqo("cliqo_sk_live_xxxxxxxxxxxxxxxx");
// ou
const cliqo = new Cliqo(process.env.CLIQO_API_KEY!);
```

## Contatos

```typescript
// Criar
const contact = await cliqo.contacts.create({
  email: "ana@acimaq.com.br",
  first_name: "Ana",
  phone: "+5511999999999"
});

// Buscar
const contact = await cliqo.contacts.retrieve("con_xxx");

// Atualizar
const contact = await cliqo.contacts.update("con_xxx", {
  subscribed: false
});

// Listar
const { data, total } = await cliqo.contacts.list({
  page: 1,
  limit: 50
});

// Deletar
await cliqo.contacts.delete("con_xxx");
```

## Campanhas

```typescript
// Enviar imediatamente
const campaign = await cliqo.campaigns.send({
  from: "Loja <contato@loja.com.br>",
  to: "list_xxx",
  subject: "Novidades da semana",
  template: "quiz_recommendation"
});

// Agendar
const campaign = await cliqo.campaigns.send({
  from: "Loja <contato@loja.com.br>",
  to: ["cliente1@gmail.com", "cliente2@gmail.com"],
  subject: "Promoção especial",
  template: "spin_wheel",
  scheduled_at: "2026-05-25T09:00:00-03:00"
});

// Cancelar agendamento
await cliqo.campaigns.cancel("cmp_xxx");
```

## Tratamento de erros

```typescript
import { Cliqo, CliqoError } from "cliqo";

const cliqo = new Cliqo(process.env.CLIQO_API_KEY!);

try {
  const contact = await cliqo.contacts.create({
    email: "invalido"
  });
} catch (error) {
  if (error instanceof CliqoError) {
    console.error(error.code);    // "invalid_email"
    console.error(error.message); // "The email address is invalid."
    console.error(error.status);  // 400
  }
}
```

## TypeScript

O SDK inclui tipagens completas:

```typescript
import type { Contact, Campaign, CampaignStatus } from "cliqo";

const status: CampaignStatus = "sent"; // "queued" | "sending" | "sent" | "scheduled" | "failed"
```
