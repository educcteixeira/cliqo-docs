# Quickstart

Envie um email AMP interativo com a API da Cliqo em 3 passos.

## 1. Instale o SDK

<CodeGroup>

```bash npm
npm install cliqo
```

```bash pip
pip install cliqo-python
```

```bash yarn
yarn add cliqo
```

</CodeGroup>

## 2. Envie um email

<CodeGroup>

```javascript Node.js
import { Cliqo } from "cliqo";

const cliqo = new Cliqo("cliqo_sk_live_xxxxxxxxxxxxxxxx");

const { data, error } = await cliqo.campaigns.send({
  from: "Sua Loja <contato@sualolja.com.br>",
  to: ["cliente@gmail.com"],
  subject: "Novidades da semana 🎯",
  template: "quiz_recommendation", // template AMP da Cliqo
  variables: {
    nome: "Ana",
    empresa: "Sua Loja"
  }
});

if (error) {
  console.error(error);
  return;
}

console.log(data.id); // cmp_01H9Z3X2Y1K8M4N5P6Q7R8S9T0
```

```python Python
import cliqo

cliqo.api_key = "cliqo_sk_live_xxxxxxxxxxxxxxxx"

response = cliqo.campaigns.send(
    from_="Sua Loja <contato@sualoja.com.br>",
    to=["cliente@gmail.com"],
    subject="Novidades da semana 🎯",
    template="quiz_recommendation",
    variables={"nome": "Ana", "empresa": "Sua Loja"}
)

print(response.id)
```

```bash cURL
curl -X POST https://api.cliqo.io/v1/campaigns/send \
  -H "Authorization: Bearer cliqo_sk_live_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "Sua Loja <contato@sualoja.com.br>",
    "to": ["cliente@gmail.com"],
    "subject": "Novidades da semana 🎯",
    "template": "quiz_recommendation",
    "variables": {
      "nome": "Ana",
      "empresa": "Sua Loja"
    }
  }'
```

</CodeGroup>

## 3. Verifique o envio

```json Resposta
{
  "id": "cmp_01H9Z3X2Y1K8M4N5P6Q7R8S9T0",
  "object": "campaign",
  "status": "queued",
  "recipients": 1,
  "amp_supported": true,
  "created_at": "2026-05-20T10:00:00Z"
}
```

O campo `amp_supported` indica se o destinatário receberá a versão AMP interativa ou o fallback HTML automaticamente.

<Check>Pronto! Seu email foi enviado. Veja no [Dashboard](https://app.cliqo.io) as métricas em tempo real.</Check>
