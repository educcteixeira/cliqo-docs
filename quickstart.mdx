# Começo rápido

## 1. Tire uma chave

No painel: **Configurações › API › Criar chave**. Escolha o escopo — para criar
contatos, `send_only` ou `full`.

A chave aparece **uma vez só**. Copie na hora.

## 2. Confirme que ela funciona

```bash
curl -s https://app.cliqo.io/v1/me \
  -H "Authorization: Bearer cliqo_<sua-chave>"
```

Resposta:

```json
{
  "account": { "id": "…", "name": "Nome da conta" },
  "brand":   { "id": "…", "name": "Marca", "slug": "principal" },
  "key":     { "id": "…", "name": "nome que você deu à chave" },
  "can":     { "ler": true, "enviar": true, "escreverContatos": true }
}
```

Se voltar `401`, confira o cabeçalho e a chave. Se voltar `503`, é falha nossa —
tente de novo, **não troque a chave**.

## 3. Crie um contato

```bash
curl -s -X POST https://app.cliqo.io/v1/contacts \
  -H "Authorization: Bearer cliqo_<sua-chave>" \
  -H "Content-Type: application/json" \
  -d '{"email":"cliente@exemplo.com","name":"Cliente"}'
```

Pronto — é toda a API que existe hoje. A referência completa de
`POST /v1/contacts` está [aqui](/api-reference/contacts/create).
