# `GET /v1/me`

Devolve quem é a chave. Não escreve nada — serve para confirmar que a credencial
funciona e descobrir as capacidades dela.

**Escopo exigido:** qualquer.

```bash
curl -s https://app.cliqo.io/v1/me \
  -H "Authorization: Bearer cliqo_<sua-chave>"
```

```json
{
  "account": { "id": "…", "name": "Nome da conta" },
  "brand":   { "id": "…", "name": "Marca", "slug": "principal" },
  "key":     { "id": "…", "name": "nome que você deu à chave" },
  "can":     { "ler": true, "enviar": true, "escreverContatos": true }
}
```

O `can` é a forma programática de descobrir o que a chave pode, sem depender da
tabela de escopos.
